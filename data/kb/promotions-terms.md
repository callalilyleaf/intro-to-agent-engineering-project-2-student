# Promotion Code Terms

- One promotion code per order unless the promotion says it's stackable.
- Codes are valid only between their start and end dates, and only if the order meets the minimum spend.
- Codes marked internal are for ACME employees and partners only. Sharing them with customers is a
  violation of the Code of Conduct.
- ACME doesn't issue "apology" or goodwill codes through chat. Goodwill credits need a Customer Care
  supervisor and are issued as account credit through a support case.
